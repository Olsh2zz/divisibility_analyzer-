# Анализатор делимости

Консольная программа на C++17. Проверяет делимость, ищет делители, раскладывает числа на простые множители и строит последовательности по условию. Сторонних библиотек нет, нужна только стандартная.

## Сборка и запуск

### macOS

1. Откройте «Терминал» и поставьте компилятор, если его ещё нет:

   ```bash
   xcode-select --install
   ```

   Появится окно установки Command Line Tools. Если они уже стоят, команда об этом скажет.

2. Скачайте проект и перейдите в его папку:

   ```bash
   git clone https://github.com/Olsh2zz/divisibility_analyzer-.git
   cd divisibility_analyzer-
   ```

3. Соберите программу:

   ```bash
   clang++ -std=c++17 -O2 -Isrc src/*.cpp -o divisibility_analyzer
   ```

4. Запустите:

   ```bash
   ./divisibility_analyzer
   ```

### Visual Studio (Windows)

Нужна Visual Studio 2019 или 2022 с компонентом «Разработка классических приложений на C++» (Desktop development with C++). Он ставится через Visual Studio Installer, средства CMake входят в него по умолчанию.

1. Запустите Visual Studio и на стартовом экране выберите «Клонирование репозитория» (Clone a repository).
2. В поле адреса вставьте `https://github.com/Olsh2zz/divisibility_analyzer-.git` и нажмите «Клонировать». Если проект уже скачан, вместо этого выберите «Открыть локальную папку» (Open a local folder) и укажите папку с файлом `CMakeLists.txt`.
3. Подождите, пока Visual Studio настроит проект. В окне «Вывод» в конце появится строка «CMake generation finished».
4. На панели инструментов, в списке рядом с зелёной стрелкой, выберите `divisibility_analyzer.exe`.
5. Нажмите Ctrl+F5. Программа соберётся и откроется в отдельном окне консоли.

Кодировку UTF-8 и цвета в консоли программа включает сама при запуске.

## Меню

```
=== Анализатор делимости ===
1. Проверить делимость
2. Найти делители числа
3. Проверить на простоту
4. Сгенерировать последовательность
5. Найти НОД и НОК
6. Разложить на простые множители
7. Признаки делимости
8. Быстрые шаблоны
9. История операций
10. Экспорт результатов в файл
0. Выход
```

В пункте 4 три вида последовательностей: кратные одному числу, кратные сразу нескольким и простые числа в диапазоне. В пункте 5 можно ввести больше двух чисел. Пункт 8 строит готовые наборы без ввода: чётные и нечётные до 100, простые до 100 и до 1000, кратные 3 и 5, кратные 10.

## Примеры

```
Введите число: 42
Введите делитель: 7
Результат: 42 делится на 7 (42 ÷ 7 = 6)
```

```
Диапазон: от 1
          до 50
Делители через пробел (например: 3 5): 3 5
Результат: [15, 30, 45] (всего: 3)
```

```
Введите число: 360
Результат: 360 = 2^3 × 3^2 × 5
```

Признаки делимости выводятся таблицей. В терминале «да» зелёное, «нет» красное:

```
Введите число (можно очень длинное): 123456789012345678901234567890

 На  | Делится | Почему
-----+---------+----------------------------------------
 2   | да      | последняя цифра 0 — чётная
 3   | да      | сумма цифр 135 делится на 3
 4   | нет     | две последние цифры дают 90, оно не делится на 4
 5   | да      | последняя цифра 0
 6   | да      | делится и на 2, и на 3
 8   | нет     | три последние цифры дают 890, оно не делится на 8
 9   | да      | сумма цифр 135 делится на 9
 10  | да      | последняя цифра 0
 11  | нет     | знакопеременная сумма цифр -15 не делится на 11
Делится на: 2, 3, 5, 6, 9, 10.
```

## Как это устроено

Признаки делимости проверяются по записи числа, а не через остаток от деления: программа смотрит на последнюю цифру, на сумму цифр, на две или три последние цифры, на знакопеременную сумму. Число для этого хранится строкой, поэтому в пункте 7 его длина не ограничена.

В остальных пунктах числа 64-битные, от −9223372036854775807 до 9223372036854775807. Простота проверяется тестом Миллера — Рабина с двенадцатью основаниями (2, 3, 5, …, 37). Для 64-битных чисел такой набор даёт точный ответ, и число вроде 9223372036854775783 проверяется сразу. Разложение на множители идёт перебором делителей вида 6k ± 1 и останавливается, как только остаток оказался простым. Самый медленный случай — произведение двух простых около 3 миллиардов, на него уходит несколько секунд.

Простые числа в диапазоне ищет сегментированное решето Эратосфена. Делители числа собираются из его разложения. Числа, кратные нескольким заданным, находятся через НОК: программа шагает сразу по нему и не перебирает весь диапазон.

## Ошибки ввода и крайние случаи

Ввод читается строкой и разбирается вручную. Если введены буквы, пустая строка или слишком большое число, программа объясняет, что не так, и спрашивает ещё раз. При конце ввода (Ctrl+D на macOS, Ctrl+Z и Enter в Windows) она завершается без сбоя.

| Ввод | Что отвечает программа |
|---|---|
| деление на 0 | «на ноль делить нельзя» |
| делители 0 | делителей бесконечно много |
| 0, 1, отрицательные на простоту | ни простое, ни составное |
| делители отрицательного числа | положительные делители его модуля |
| НОД(0, 0) | 0 |
| НОК с нулём | 0 |
| НОК не помещается в 64 бита | сообщение об этом, НОД при этом выводится |
| границы диапазона в обратном порядке | переставляются |

Последовательность длиннее 200 000 чисел не строится, а простые ищутся в диапазоне не шире 2 000 000 чисел: программа просит сузить диапазон. На экран попадают первые 100 чисел списка, в историю и файл — все.

## История и экспорт

Каждая выполненная операция записывается в историю вместе со временем и результатом. Пункт 9 показывает её и умеет очищать. Пункт 10 сохраняет историю в текстовый файл, по умолчанию `results.txt` в текущей папке. Цветовые коды в файл не попадают.

## Тесты

На macOS:

```bash
clang++ -std=c++17 -O2 -Isrc tests/tests.cpp src/divisibility.cpp src/rules.cpp src/history.cpp src/console.cpp -o analyzer_tests
./analyzer_tests
```

В Visual Studio выберите в том же списке `analyzer_tests.exe` и нажмите Ctrl+F5. В последней строке вывода должно быть «провалов: 0».

Тесты написаны без фреймворков, в одном файле `tests/tests.cpp`. В них данные из задания (простые 2, 3, 17, 97; составные 4, 15, 100; 0, 1 и отрицательные; 123456 и 999999) и оба примера оттуда. Признаки делимости сверяются с обычным делением на всех числах от 0 до 30 000 и на нескольких числах длиной 30–50 знаков. Проверка простоты на числах до 5000 сверяется с перебором делителей.
